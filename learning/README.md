# 學習筆記（圖文原理解說 × C# 對照）

這裡記錄本專案各核心階段的深度技術筆記，搭配實測影片實際產出的中間過程圖（並可於本機網頁工具的「幕後檢視」分頁互動查看）。

## 章節目錄

- `01_stage1_video_and_roi.md` — 電腦視覺基礎：影片元資料、幀差運動量、相位相關捲動追蹤、Laplacian 銳利度、HSV 色彩空間與自動 ROI 定位
- `02_stage2_ocr_and_dedup.md` — OCR 工程實務：影像前處理、1～3 名徽章模板比對、中/英/泰多語系路由、跨影格投票與業務防呆稽核
- `03_stage3_icon_clustering.md` — 免訓練圖片分類：圓形遮罩、HSV 色彩與結構特徵向量、餘弦相似度矩陣與層次式分群
- `04_stage4_analytics_and_stats.md` — 資料工程與統計：Pandas 整理、Set vs Multiset 組合統計、Lift 優勢比與 Spearman 排名相關性
